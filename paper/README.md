# Paper sources

LaTeX sources for the project paper. The PDF is **not** committed; it is
regenerated from these sources by the user.

## Files

| Path | Purpose |
|---|---|
| `load_forecasting_paper.tex` | Main document. Self-contained article-class. |
| `refs.bib` | BibTeX bibliography. |
| `fig_iters_histogram.png` | Figure 1. Generated by `_make_iters_histogram.py`. |
| `fig_calibration_curve.png` | Figure 2. Copied from `output/06b_calibration_curve.png`. |
| `fig_segment_profiles.png` | Figure 3. Copied from `output/02_segment_profiles.png`. |
| `_make_iters_histogram.py` | Regenerates Figure 1 from `output/06_lgb_iterations.csv`. |

## Compilation

The paper compiles with `latexmk`:

```bash
cd paper/
latexmk -pdf load_forecasting_paper.tex
```

If `latexmk` is not available, the manual sequence is:

```bash
pdflatex load_forecasting_paper
bibtex   load_forecasting_paper
pdflatex load_forecasting_paper
pdflatex load_forecasting_paper
```

Output: `load_forecasting_paper.pdf` (about 11 pages).

The paper depends on the following standard LaTeX packages, all part of a
TeX Live full install: `inputenc`, `fontenc`, `geometry`, `amsmath`,
`booktabs`, `graphicx`, `caption`, `hyperref`, `natbib`. No custom
`.sty` files are required.

## Regenerating figures

If `output/06_lgb_iterations.csv` changes (e.g. after a new walk-forward
run), regenerate Figure 1:

```bash
python paper/_make_iters_histogram.py
```

Figures 2 and 3 are byte-identical copies of the dashboard PNGs and only
need to be re-copied if the upstream output changes:

```bash
cp output/06b_calibration_curve.png paper/fig_calibration_curve.png
cp output/02_segment_profiles.png   paper/fig_segment_profiles.png
```

## Numbers in the paper

Every quantitative claim in the paper is sourced from a CSV under
`output/`. The following table gives the source for each table and inline
number block:

| Paper element | Source CSV |
|---|---|
| Iteration distribution (Fig. 1, §5.1) | `output/06_lgb_iterations.csv` |
| MAPE table (Tab. 2, §5.2) | `output/06_metrics_summary.csv` |

| Lift table (Tab. 4, §5.4) | computed from `output/06_metrics_summary.csv` |
| Champion iters (§3.2) | `output/05_lgb_training_summary.csv` |
| Archetypes table (Tab. 1, §4) | `output/02_segment_characterization.csv` |
| k-sweep (§4) | `output/02_ksweep_diagnostic/ksweep_metrics.csv` |
| Feature importance (§6) | `output/10_feature_importance_grouped.csv` |

If any of those CSVs change, the corresponding table or paragraph in
`load_forecasting_paper.tex` needs to be updated by hand. Numbers are
not auto-loaded at LaTeX compile time.

## Citations

`refs.bib` contains six entries. All are real publications; volume /
page numbers were checked against the publisher record as of the time of
writing. Two notes:

- The GoiEner Zenodo dataset is the primary citation for the data; if a
  Scientific Data data-descriptor article exists with verifiable
  volume/page, swap or supplement the `@misc{quesada2024goiener}` entry
  before submission.
- `vovk2005` is a book-length reference; the per-chapter citation in the
  paper points to the conformal-prediction framework as a whole, not to
  a specific page.
